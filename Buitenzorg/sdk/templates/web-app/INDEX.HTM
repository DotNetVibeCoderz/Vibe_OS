__APPNAME__

A web app for Buitenzorg OS, made with bz new web-app. It is a page on /disk, shown by the browser (Peramban).

What the browser understands

  • Headings, paragraphs, lists, links, bold and italic
  • Pictures (PNG, JPEG, GIF, BMP) with <img>
  • CSS: colors, backgrounds, borders, margins, padding, font size

Next steps

Edit INDEX.HTM and STYLE.CSS, then bz deploy . --no-run and open the page again. About this app
