# Theme packages

`*.thm` files here go onto every image as `/disk/THEMES/NAME.THM`. Format:
see `senja.thm` (every key optional except `name`; missing keys come from
`base`). Keys: `name`, `base`, `dark`, `desktop_top`, `desktop_bottom`,
`gradient`, `win_body`, `win_title_active`, `win_title_inactive`,
`win_border`, `border` (px), `title_style` (flat / beveled / tab),
`shadow_style` (none / soft / hard), `text`, `title_text`, `taskbar_bg`,
`accent`, `cursor`, `shadow`, `glass` (0-255). Guide: `docs/themes.md`.
