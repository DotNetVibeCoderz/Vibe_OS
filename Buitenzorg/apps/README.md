# apps/ — Preloaded Suite

Tempat aplikasi bawaan (requirements.md §12): utilities, multimedia, AI apps,
games, productivity, dan Store.

**Status: belum dimulai.** Aplikasi bawaan datang di **v0.16 "Panen"**, dibangun
di atas **managed runtime C# lengkap (GC + .NET BCL) dari v0.15 "Matang"** —
setelah app framework (v0.8–0.9) dan theme engine (v0.10) tersedia.

Sampai app framework siap, contoh app yang bisa dijalankan hari ini (di host
simulation) ada di `runtime/samples/` dan template di `sdk/templates/`.
